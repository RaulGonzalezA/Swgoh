# Investment Optimizer: coste / beneficio

El Investment Optimizer combina el impacto funcional de cada unidad con un indice de coste relativo cuando existe un objetivo concreto de reliquia o estrellas.

- **Impact score**: valor transversal ya calculado a partir de GAC, RotE, Conquista, Era y Coliseo.
- **Cost index**: esfuerzo relativo del salto objetivo. Los niveles altos de reliquia pesan mas que los bajos y los saltos de estrellas se ponderan de forma incremental.
- **Impact / cost**: impacto dividido por coste relativo.
- **Value score**: mezcla de impacto y eficiencia para ordenar mejoras con retorno alto sin convertir el coste en una falsa lista exacta de materiales.

El indice de coste es deliberadamente relativo. No descuenta inventario, fragmentos parciales, materiales ya acumulados ni recursos de eventos/tiendas, por lo que la UI lo etiqueta siempre como estimacion.
